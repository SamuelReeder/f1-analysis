# Paired Overall simulation resource workload

This definition is committed before measurement. It measures the existing
paired simulation and accumulation path at the committed field and reference
calendar dimensions. It does not fit a model, evaluate real driver performance,
complete the nested posterior workload or establish simulation precision.

Run the largest permitted draw-by-replicate block from `overall_summary.py`,
including the baseline and every declared explanation for every entrant. Use
the complete reference calendar, its virtual race distances and the existing
qualifying format for the field. Each event has its own synthetic coefficient
context. All races have explicit full racing distance and zero retirement
hazard for this resource fixture. These are workload assumptions, not a
calibrated completion model.

Use the fixed synthetic parameter formulas and seed in
`analysis/overall_simulation_resources.py`, committed before execution.
Qualifying and race states vary across both drivers and draw lanes so that
neutralizing a component is not uniformly a no-op. Observation scales and
context coefficients are arbitrary fixed constants. There is no posterior
archive, convergence claim or selection among simulation outcomes.

Allocate and touch the complete summary arrays at the initial and largest
existing retry posterior shapes, sequentially. Retain the larger accumulator
while generating and adding the full block. Record accumulator bytes, output
array bytes, process peak resident memory and stage durations. Verify that the
incomplete workload cannot finalize. Save input/output fingerprints and counts,
not a synthetic or real driver ranking.

Calculate, but do not execute, the complete schedule at those posterior shapes
using the smallest even replicate count meeting the existing paired-difference
worst-case error bound. Record its block and season counts explicitly as planned
work. Do not extrapolate total runtime from this single measured block or claim
that an unexecuted schedule passed its precision checks. The full accepted
workload still requires its own frozen registration and measurement.

Use the required local capped scope. Bind the exact committed source, field
reference, calendar, processed race data and pending numerical proposal before
execution, and recheck them on completion. Record numerical runtime identity,
the enforced limits and monotonic and UTC timestamps. Preserve errors and the
last completed stage in the output directory. Do not overwrite or automatically
retry an existing attempt, reduce the block or loosen a bound after a result.

This measurement can identify engineering costs. Any subsequent implementation
optimization must preserve the defined distribution, stream schedule, complete
draw inventory, paired explanatory meaning and failure behavior, and must be
checked against the existing implementation before it is adopted. A faster
implementation does not establish scientific acceptance or permit publication.
