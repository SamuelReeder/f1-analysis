# Legacy pre-qualifying integration: synthetic resource workload

This definition is committed before measurement. The workload uses the current
committed qualifying design through the interface-preflight cutoff, retaining
every state coordinate needed by the legacy forecast. It does not fit a model,
score a real race, select baseline fitting settings or establish calibration.

The draw axes use the largest existing retry shape defined by the committed
fitting settings and retry ladder, independently for qualifying parameters and
joint race-coefficient vectors. The coefficient coordinates all vary; their
within-vector dependence is preserved. Arbitrary synthetic raw qualifying
coordinates and the existing resource-fixture scalar values supply a hypothetical
future field at a known circuit. No actual target grid or result is supplied.

Generate the full qualifying-grid inventory using the existing explicit
all-set-times/no-penalties scenario and qualifying-format mapping. For each of
the legacy-feature and grid-only race arms, evaluate the full empirical product
of qualifying grids and race coefficients. Duplicate grids retain their integer
weights. Do not discard draws, rare grids or coefficient vectors to reduce cost.
Use the committed default bounded blocks throughout.

Record input hashes, source commit, full draw and combination counts, finite
conditional probability checks, stage durations and process peak resident memory.
The workload must run in the user's capped scope. Keep failed runs as evidence;
an arithmetic-preserving implementation correction requires a new source identity
and a separately retained measurement. There is no predictive acceptance gate in
this resource check and no ranking is produced.

The existing small known-probability tests check the integration arithmetic.
This workload adds coverage at the committed data and retry dimensions, but does
not establish forecast replication precision, convergence, real-data predictive
performance, official-grid treatment, hosted-runner resources or deployment
readiness. Archive decompression has its own previously recorded workload; this
measurement reads synthetic maps directly and isolates pre-qualifying integration.
