# Review of the corrected computational profile

This collector is separate from the frozen fitting sources. Run it only after
the registered service is authoritatively terminal and its complete raw output
inventory has been committed. It does not poll, restart, fit, change a numerical
criterion or authorize publication.
Write the review outside the original profile output and cache directories;
putting the report among its own inputs would change the inventory it verifies.

The previous complete-design reviewer expects the previous registration and
preflight formats. The corrected-profile reviewer uses the current registration
validator and preflight inventory, and reuses the existing fixed-ladder and
driver-contrast inventory checks. It retains every required case, including a
failed child or a child killed before writing a result. A missing whole-run
summary is an interrupted run requiring a separate recovery decision; the
reviewer does not manufacture completion.

A current systemd query must show either a terminal loaded service or an absent
service with no main process. A completed transient unit need not remain loaded.
The complete committed summary and matching launcher exit record are required
in either case. Service absence alone cannot supply a successful run or replace
missing results. Recheck this authoritative service state before returning.

Check the complete child-result inventory against the summary, then bind each
child's log, resource record, result, generating truth and cached receipt.
Compare the receipt's specification, method, source, original generated inputs,
catalogue and sampling settings with the frozen inputs. Check every attempt's
complete declared posterior inventory and sampler-extra archive fingerprint.
Retain failed-attempt archives and account for unexpected cache files. A
successful fit's archive cannot hide a missing failed attempt or an omitted
sampler archive.

Recheck all collected fingerprints and the terminal service before returning.
Record the complete receipts and per-attempt reports, keeping child elapsed time
and its separate external resource log distinct. The independent current-driver
contrast decisions remain separate from the fitter's unchanged parameter gate;
their failure must remain visible even when the fitter reports convergence.

This is metadata and byte-identity verification. It does not open numerical
arrays, recompute diagnostics, authenticate recorded parameter decisions,
recompute recovery metrics or establish functional precision. Consistent failure
records are a successful review of a failed experiment. Independent saved-array
verification, complete scientific acceptance and the remaining production plan
are still required. No flag in this review permits a ranking or publication.

Software checks use invented metadata and archive bytes. They must reject
changed source identities, incomplete retained fields, missing or changed sampler
files, altered retries, skipped failed attempts and contradictory completion
flags. They must retain later cases after a failed or killed child. Preparation
of this reviewer is not evidence that the active experiment has finished.
