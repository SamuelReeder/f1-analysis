# Diagnostic-moment storage resource fixture

This definition precedes measurement. Exercise archive writing, checked reading
and retained array equality at the largest existing retry chain/draw shape and
the committed field size. Use the existing paired-error range bound for the
replicate count. This is a storage-format fixture, not a fit, canonical weekend
simulation, completed posterior workload or numerical acceptance study.

Construct varied, physically bounded point moments from a fixed finite mixture
of full-field permutations of the existing points table. Generate multinomial
class counts for the declared replicates and calculate means and unbiased sample
covariances directly from those counts. Explanation-loss fixtures pair each class
with fixed cyclic permutations of its points, using the same class counts.
These arbitrary discrete outcomes are not a model of real driver performance.
Freeze the formulas and seed in the resource script before executing it.

Write the companion into a temporary directory. A synthetic receipt and summary
exercise the checked format with explicit placeholder fit identities and all
scientific/publication flags false. They supply no authentic fit or convergence
evidence, and are removed after the check. Keep only the resource report, source
fingerprints and array/archive fingerprints. Record the fact that this isolated
format fixture supplies its own consistency metadata.

Verify every loaded array equals the supplied array and that loaded arrays are
read-only. Measure construction, writing and reading separately, record array
and archive bytes, process peak resident memory and the enforced local caps.
Preserve failures, do not reduce the dimensions or alter a threshold after a
measurement, and do not infer full-controller or intended-runner feasibility.
